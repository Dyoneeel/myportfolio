RAWR CASINO

Decentralized Web Application

About This Project

RAWR casino is a decentralized e-casino platform where users can mine RAWR tokens, exchange them for casino tickets to bet, win, and earn using our custom crypto token. The goal was to create a functional and engaging gaming environment that leverages blockchain for transparent and secure transactions. I was responsible for both the front-end user interface and the back-end logic, including the smart contract integration.

Key Features

  • Mine RAWR token and convert to casino tickets.
  • Play 5 different casino games to earn more tickets.
  • Convert tickets back to RAWR token.
  • Withdraw RAWR token directly to a Metamask wallet.
  • Secure and transparent betting system via blockchain.
