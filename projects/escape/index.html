Project Overview

Escape is a Flutter mobile game inspired by Snake and Ladder. It supports offline local multiplayer and adds portals, wormholes, and power-ups to the core board-game concept.

My Role

I worked as the Frontend Developer, focusing on the mobile interface and the player-facing experience.

Key Features

  • Offline local multiplayer
  • Snake-and-Ladder-inspired board gameplay
  • Portals and wormholes
  • Power-up mechanics
  • Player race toward the final tile
